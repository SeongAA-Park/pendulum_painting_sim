# Spherical pendulum simulation

Pygame과 NumPy를 사용한 감쇠 구면 진자의 궤적 시뮬레이션입니다. 위에서 본 화면과 옆에서 본 화면을 각각 실행할 수 있습니다.

## 실행

Python 가상환경에서 `pip install -r requirements.txt`로 의존성을 설치한 뒤 다음 중 하나를 실행하세요.

```bash
python "(top)spherical_pendulum_with_dissipation_2020251096_박성아.py"
python "(side)spherical_pendulum_with_dissipation_2020251096_박성아.py"
```

`T` 키로 궤적 표시를 전환하고, `C` 키로 궤적을 지울 수 있습니다.

## 제작 목적과 원본 출처

이 코드는 교육·학습 목적으로 작성한 감쇠 구면 진자 시뮬레이션입니다. 구면 진자의 운동 및 화면 구현에는 apf99의 [SphericalPendulumAnimation](https://github.com/apf99/SphericalPendulumAnimation) 저장소에 공개된 코드를 참고했습니다. 원본 코드의 저작권은 원저작자에게 있습니다.

## 이용 조건

이 저장소는 별도의 오픈소스 라이선스를 제공하지 않습니다. 작성자가 권리를 보유한 부분에 대해서는 사전 허락 없는 재배포, 복제물 공개 및 상업적 이용을 허용하지 않습니다. 이 자료는 교육·학습 목적으로 작성했습니다.

원본 저장소의 공개 파일 목록에서는 별도 라이선스 파일을 확인하지 못했습니다. 이 안내는 원본 코드에 대한 이용 권한을 부여하지 않으며, 원본 코드의 복제·수정·배포가 필요한 경우 원저작자의 이용 조건과 허락을 별도로 확인해야 합니다.
